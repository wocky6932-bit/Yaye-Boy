# 🌸 Projet Anniversaire Mbarka - 31 Octobre 🌸

Ce dossier contient le site web d'anniversaire interactif créé sur mesure pour **Mbarka**, ainsi que sa carte cadeau avec QR Code prête à imprimer pour le bouquet de fleurs.

## 📂 Contenu
- `index.html` : Le site web interactif mobile-first complet (photos, vidéos, cartes secrètes, lettre, musique, confettis).
- `style.css` : Design haute couture (noir satiné, or & champagne, animations fluides).
- `script.js` : Interactions tactiles, lecteur multimédia, confettis, ouverture d'enveloppe.
- `carte_qr.html` : Carte de vœux imprimable pour le fleuriste avec le QR Code haute résolution.
- `assets/` :
  - `images/` : 10 photos classées et optimisées.
  - `videos/` : Les 3 vidéos mp4 intégrées.
  - `music/` : Musique de fond d'ambiance.

## 🚀 Comment l'héberger en 2 minutes (Gratuit) :
Pour que le QR Code fonctionne sur le téléphone de Mbarka :
1. Glisser le dossier sur **Netlify Drop** (app.netlify.com/drop) ou **Vercel** / **GitHub Pages**.
2. Tu obtiendras un lien web instantané (ex: `https://mbarka-anniversaire.netlify.app`).
3. Mettre ce lien dans `carte_qr.html` pour générer le QR Code final à imprimer !
